Info și metodologie

Ce se actualizează, când și cum trebuie interpretate datele.

Program

Actualizarea automată rulează de luni până vineri, la 22:00 UTC: aproximativ 01:00 vara și 00:00 iarna în România.

Rulează după închiderea normală a pieței SUA. GitHub poate întârzia ocazional pornirea unui job programat.

Durată

Cu Finnhub, colectarea poate dura sub un minut. Dacă sursa intră în fallback Twelve Data, poate dura circa 4–5 minute, deoarece respectă limita de 8 cereri/minut.

GitHub Pages publică apoi datele noi, de regulă în încă aproximativ un minut.

Chei și confidențialitate

Cheile Finnhub și Twelve Data sunt păstrate numai în GitHub Secrets. Browserul primește doar fișiere JSON generate, niciodată cheile API.

Scor rotație

Scorul este între −10 și +10: trendul (50D/200D) are 40%, forța relativă la SPY pe 1M/3M are 40%, iar direcția de 5D și volumul au 20%.

Randamentul de 1 an, când este folosit ca referință, este randament de preț, nu total return cu dividende reinvestite.

Flux capital

Nu folosim AUM împărțit la preț. Fluxul este bazat pe variația reală a unităților în circulație publicate de emitent.

Flux USD ≈ Δ unități × ultimul preț de închidere. Este o estimare, nu o valoare contabilă de tranzacționare.

Praguri utile

Pentru fluxuri, sub ±0,5% este de regulă zgomot. Peste ±2% devine semnal care merită analizat în contextul prețului și al scorului de rotație.

Schimbările extreme trebuie verificate, deoarece pot fi split-uri, schimbări de structură sau întârzieri de raportare.

Surse și limite

  • Prețuri și volume: Finnhub, cu Twelve Data ca fallback.
  • Shares outstanding validate: paginile oficiale iShares, cu data „as of” afișată în pagină.
  • ETF-urile State Street/SPDR, Invesco, VanEck, Global X, First Trust și Vanguard sunt încă „În pregătire” pentru fluxuri, până conectăm și validăm sursele lor oficiale.
  • În zile fără sesiune, sau când emitentul nu publică o dată nouă, nu apare un flux nou. Datele lipsă nu sunt completate cu zero sau cu AUM.
